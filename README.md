A Python program that writes one original one-line joke about office life — the shared-fridge labelling trick — to `/output/entry.txt` (111 characters, single line, UTF-8).

## The joke

> The office fridge says 'label your food', so I labelled mine 'Dave's' and nobody has touched it in three weeks.

`main.py` asserts the joke is a single line of 1–200 characters before writing it, and verifies the written file round-trips inside those limits.

## Run it

```sh
python3 main.py
```
